# Minecraft Clone (Sort of)
A very simple minecraft 'clone' (not sure if you can really call it that) I wrote during the pandemic around 2020-2021.
## How to get going
Make sure that you use python 3.11, if you wonder why then take a look at the following: https://github.com/pokepetter/ursina/issues/571 
1) You can install it (python 3.11) using something like pyenv:
```bash
pyenv install 3.11
```
2) After that make sure to install the required modules
```bash
python -m pip install -r requirements.txt
```
3) Run it
```bash
python main.py
```
And that's about it...
